# Style Span Notes (Structurer)
팔로업용도

## 요약
- 딥파싱은 word 기준 색상, 세그멘테이션은 공백 복원으로 text를 합침
- word 개수 != text 단어 수 → colors 길이와 매핑 기준 불일치 가능
- 구조화는 원본 colors 보존을 우선하고 fallback으로 스팬 생성
- 화면상 정상처럼 보여도 경계 정확도는 떨어질 수 있음
- 다른 PDF에서 반복되면 세그멘테이션 규칙부터 재검토 필요

## 현재 대응 로직
1) 토큰 기준 매핑 시도 (token_regex + token_break_chars)
2) 실패 시 단어(공백) 기준 매핑 fallback (text.split 기준)
3) 둘 다 실패하면 로그 기록

## 로그
- 정의: 색상 스팬을 만들 때 토큰/단어 기준 매핑이 모두 실패한 경우 기록
- 의미: colors 길이와 토큰/단어 기준 매핑이 모두 실패한 라인
- issue 코드: `style_span_map_failed`
  - 의미: 토큰 기준 매핑 실패 + 단어 기준 매핑 실패
  - 원인: colors 개수와 text 단어/토큰 개수가 맞지 않아 매핑 기준이 어긋난 상태
- 주의: 출력 정상이어도 경계 오류 가능
- Git 미커밋(로컬 메모)

## 향후 조치
- 다른 PDF에서 문제가 재현되면, 세그멘테이션 단계부터 규칙을 보강해야 함
- 구조화 단계만으로는 word 경계 이상의 정밀한 색상 복원이 어려움
- 세그멘테이션 보강/로그 조정은 별도 브랜치에서 테스트 후 반영 예정
